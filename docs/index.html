Video editing with an agent that understands the timeline.

Filmidi is an AI-native desktop editor for turning natural-language ideas into precise, inspectable edits across video, audio, images, text, captions, effects, and transitions.

Download for MacView releasesRun locally

Apple Silicon DMG. Add your Vercel AI Gateway API key from the welcome screen or Settings after installation.

A timeline-first editorEvery agent action is grounded in the open project state. Inspect the edit, place the result on a real track, and keep the change available for undo, saving, and export.

Built for real edits

Direct manipulation and agent workflows share the same project model, so the timeline remains the source of truth.

Multi-track timeline

Move, trim, split, ripple-delete, snap, zoom, link, and organize video, audio, image, shape, and text layers across typed tracks.

Agent editing

Let the agent inspect clips, media, transcripts, timing, effects, keyframes, and transitions before choosing the right editing tool.

Captions and transcripts

Transcribe spoken audio, build readable phrases on word boundaries, keep captions aligned to edits, and place them on dedicated text tracks.

Media and generation

Import local assets, generate or search for media, organize the library, and place selected video, images, audio, and SFX at the intended timeline position.

Creative controls

Use text, mattes, shapes, keyframes, color adjustments, effects, transitions, audio tools, and layout operations from the UI or agent.

Projects that travel

Save self-contained .filmidi packages with timeline data, media metadata, generated assets, captions, folders, and agent history.

One editing loop

Filmidi keeps intent, operations, and visible results connected.

InspectRead the timeline, media library, transcript, and project format before changing anything.
PlanChoose the smallest suitable tool and account for linked clips, occupied tracks, and aspect ratio.
EditApply a reversible timeline mutation with correct timing, track placement, and project metadata.
VerifyRe-read the timeline and preview state, then save or export the actual edited project.

Under the hood

Desktop-native packaging with a focused editor runtime and optional macOS acceleration.
