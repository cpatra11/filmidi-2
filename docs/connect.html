Connect Filmidi to MCP.

Use Filmidi’s local MCP server to let an MCP-compatible client inspect the timeline, media library, transcript, and editing tools. Configure your own Qwen key in the app; credentials stay on your machine.

1. Start Filmidi

Open the Filmidi app. Its local MCP server starts with the app and listens on loopback:

http://127.0.0.1:19790/mcp

The server is local-only. Filmidi must remain open while an external MCP client is connected.

2. Configure an MCP client

Add Filmidi as an MCP server in the client’s MCP configuration. For HTTP MCP clients, use:

{
  "mcpServers": {
    "filmidi": {
      "url": "http://127.0.0.1:19790/mcp"
    }
  }
}

Restart or reconnect the MCP client after saving its configuration. The client should complete the MCP handshake, then expose Filmidi’s timeline and media tools.

3. Add your Qwen BYOK key

  1. Open Filmidi and go to the welcome screen or Settings → Agent.
  2. Choose the Qwen-compatible provider and paste your API key into the API key field.
  3. Save or test the connection, then select the desired available model.
  4. Return to the agent panel and send a request grounded in the open timeline.
Filmidi does not package an API key in the DMG or source repository. The key is stored in the app’s local credential store and is only used for requests from your installation. Never commit it to a project or share it in chat.

4. Verify the connection

In the MCP client, call the tool list or ask Filmidi for the current timeline. A healthy connection returns the MCP tools and project state. In Filmidi, the MCP status and diagnostic logs are available from the help or agent tooling.

Common problems

Server already initialized: disconnect the old MCP session and create one fresh connection. Each client should reuse its session instead of sending a second initialize request.

Connection refused: open Filmidi first and confirm the client is using port 19790.

Not Acceptable: the client must support MCP’s text/event-stream response type; use an MCP-compatible connector rather than opening the endpoint as a normal webpage.

Transcription or generation errors: verify the Qwen key, selected model, network access, and the processing mode in Filmidi Settings.

Use the agent effectively

Ask the agent to inspect the timeline before editing. Useful requests include: “show the current timeline,” “add captions to spoken clips,” “place this image when ‘screen’ is said,” “remove only transcript-confirmed pauses,” and “export the edited timeline.” The agent should verify the result with a fresh timeline read after each operation.
